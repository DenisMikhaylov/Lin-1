# Лабораторная работа
## Работа с файлами в Midnight Commander (`mc`) и редакторе `mcedit` в Debian 12

**Цель работы:** освоить двухпанельный файловый менеджер Midnight Commander и встроенный редактор `mcedit` для выполнения типовых операций с файлами и каталогами: навигации, создания, копирования, перемещения, переименования, удаления, просмотра, редактирования, поиска и работы с архивами.

**Среда выполнения:** Debian 12, пользователь `debian` с правами `sudo`, терминал.

**Продолжительность:** 1 академический час.

---

## 1. Теоретические сведения

**Midnight Commander (`mc`)** — консольный двухпанельный файловый менеджер в стиле Norton Commander. Он позволяет выполнять большинство файловых операций без запоминания команд оболочки: навигация по каталогам, копирование, перемещение, удаление, просмотр, редактирование, работа с архивами, FTP/SFTP.

**Ключевые особенности:**
- Две панели (левая и правая) — удобно для копирования и перемещения между каталогами.
- Функциональные клавиши `F1`–`F10` выполняют основные действия (см. нижнюю панель).
- Встроенный редактор **`mcedit`** (`F4`) и встроенная программа просмотра (`F3`).
- Поддержка архивов «как каталогов»: можно зайти в `.tar.gz`, `.zip` и работать с содержимым без распаковки.
- Встроенная командная строка внизу экрана — можно вводить команды Bash.

**Установка (если не установлен):**
```bash
sudo apt update
sudo apt install -y mc
```

**Проверка:**
```bash
which mc
which mcedit
mc --version
```

**Важно про функциональные клавиши.** В некоторых терминалах (особенно в SSH-клиентах и эмуляторах вроде PuTTY) `F1`–`F10` перехватываются. Тогда используйте `Esc` + цифра: `Esc 1` = `F1`, `Esc 4` = `F4`, `Esc 0` = `F10`. В VirtualBox по умолчанию `Host`-клавиша — правый `Ctrl`.

## 2. Задание 1. Подготовка рабочего каталога

Создайте структуру каталогов для работы:

```bash
mkdir -p ~/mc_lab/source ~/mc_lab/dest ~/mc_lab/archive
cd ~/mc_lab/source
touch file1.txt file2.txt file3.log
echo "Содержимое первого файла" > file1.txt
echo "Содержимое второго файла" > file2.txt
mkdir -p subdir1 subdir2
echo "Внутри подкаталога" > subdir1/inside.txt
ls -R ~/mc_lab
```

## 3. Задание 2. Запуск `mc` и навигация

### 3.1. Запуск

```bash
mc
```

Откроется двухпанельный интерфейс. Внизу — строка функциональных клавиш и командная строка.

### 3.2. Основные клавиши навигации

| Клавиши | Действие |
|---|---|
| `↑` / `↓` | Перемещение по списку файлов |
| `PgUp` / `PgDn` | Страница вверх/вниз |
| `Home` / `End` | В начало/конец списка |
| `Tab` | Переключение между панелями |
| `Enter` | Войти в каталог / открыть файл |
| `Backspace` | Перейти в родительский каталог |
| `Ctrl + \` | Показать меню «быстрого доступа» (hotlist) |
| `Alt + .` | Показать/скрыть скрытые файлы |
| `Ctrl + O` | Показать/скрыть панели (вернуться в shell) |
| `Ctrl + U` | Поменять панели местами |
| `Alt + I` | Синхронизировать каталоги на панелях |

### 3.3. Навигация на практике

1. Установите левую панель в `~/mc_lab/source`, правую — в `~/mc_lab/dest`. Перемещаться между панелями — `Tab`. Переход в каталог — `Enter`.
2. Включите отображение скрытых файлов (`Alt + .`). Убедитесь, что появились `.` и `..`.
3. Войдите в `subdir1` на левой панели и вернитесь назад через `Backspace`.
4. Поменяйте панели местами (`Ctrl + U`) и убедитесь, что содержимое поменялось.

> В нижней строке `mc` всегда отображается текущий каталог активной панели и подсказки по клавишам.

## 4. Задание 3. Создание файлов и каталогов в `mc`

### 4.1. Создание каталога

На левой панели (`~/mc_lab/source`) нажмите `F7`. Введите имя `newdir` и подтвердите. Убедитесь, что каталог появился.

### 4.2. Создание файла

`mc` не имеет отдельной клавиши «создать файл», но его можно создать через меню `F9 → File → Create new file` (в некоторых версиях) или через `F4` (открыть редактор с новым именем — см. задание 6). Проверьте оба способа.

### 4.3. Переименование

Выделите `file3.log` и нажмите `F6` (Move/Rename). Введите новое имя `file3_renamed.log`. Подтвердите.

## 5. Задание 4. Копирование, перемещение и удаление

### 5.1. Копирование файла на другую панель

1. На левой панели (`source`) выделите `file1.txt`.
2. Нажмите `F5` (Copy). В диалоге по умолчанию уже указан путь правой панели (`~/mc_lab/dest`). Подтвердите.
3. Проверьте правую панель — файл должен появиться.

### 5.2. Перемещение файла

1. На левой панели выделите `file2.txt`.
2. Нажмите `F6` (Move). Подтвердите путь на правой панели.
3. Убедитесь, что `file2.txt` исчез с левой панели и появился на правой.

### 5.3. Копирование каталога

1. Выделите `subdir1` на левой панели.
2. `F5` → подтвердите копирование в правую панель. Каталог скопируется со всем содержимым.

### 5.4. Удаление

1. На правой панели выделите `file1.txt`.
2. Нажмите `F8` (Delete). Подтвердите удаление.
3. Удалите каталог `subdir1` на правой панели тем же способом (mc спросит подтверждение для непустого каталога).

### 5.5. Выделение нескольких файлов

1. На левой панели установите курсор на первом файле.
2. Нажмите `Insert` (или `Ctrl + T`) — файл подсветится.
3. Переместитесь вниз и снова `Insert` — выделено несколько файлов.
4. Теперь `F5`, `F6` или `F8` применятся ко всем выделенным файлам.
5. Снять выделение — `Insert` на каждом или `*` (инвертировать) / `+` / `-` (по маске).

## 6. Задание 5. Просмотр файлов

### 6.1. Встроенный просмотрщик

1. Выделите `file1.txt` на левой панели.
2. Нажмите `F3` — откроется встроенный просмотрщик.
3. Внутри: `F3` — выход, `F4` — переключение в редактор, `F7` — поиск, `F2` — перенос строк.

### 6.2. Просмотр бинарного файла

Выделите `/bin/ls` (перейдите в `/bin` на панели) и нажмите `F3`. Обратите внимание на шестнадцатеричный режим — переключитесь через `F2` или `F4` (в некоторых версиях).

### 6.3. Быстрый просмотр (`Ctrl + X, Q`)

Нажмите `Ctrl + X`, затем `Q` — правая панель переключится в режим «Quick view» и будет показывать содержимое файла, выделенного на левой панели. Вернуть обычный вид — снова `Ctrl + X, Q` или через меню панели.

## 7. Задание 6. Редактирование в `mcedit`

### 7.1. Открытие редактора

1. Выделите `file1.txt` на левой панели.
2. Нажмите `F4` — откроется встроенный редактор `mcedit`.

### 7.2. Основные клавиши `mcedit`

| Клавиши | Действие |
|---|---|
| `F2` | Сохранить |
| `F10` | Выйти |
| `F3` | Начать выделение блока |
| `F4` | Поиск |
| `F5` | Копировать выделенный блок |
| `F6` | Переместить выделенный блок |
| `F7` | Поиск (замена) |
| `F8` | Удалить строку |
| `F9` | Меню |
| `Ctrl + Y` | Удалить строку |
| `Ctrl + U` | Отменить |
| `Ctrl + O` | Открыть другой файл |
| `Alt + F` | Меню File |
| `Ctrl + End` | В конец файла |
| `Ctrl + Home` | В начало файла |
| `Ctrl + S` | Начать/закончить выделение блока (альтернатива `F3`) |

> Если `F-клавиши` перехватываются терминалом, используйте `Esc` + цифра: `Esc 2` = `F2`, `Esc 4` = `F4`, `Esc 0` = `F10`.

### 7.3. Практика в `mcedit`

1. Откройте `file1.txt` через `F4`.
2. Добавьте в конец файла строку `Добавлено в mcedit` (`Ctrl + End`, `Enter`, текст).
3. Найдите слово `Содержимое` через `F7`. Замените на `Содержимое_изменено`.
4. Выделите строку через `Ctrl + Y`, чтобы удалить, затем отмените через `Ctrl + U`.
5. Сохраните (`F2`) и выйдите (`F10`).
6. Проверьте результат через `F3` или командой `cat` в shell (`Ctrl + O`).

### 7.4. Создание нового файла в `mcedit`

1. На панели нажмите `Shift + F4` — откроется диалог «введите имя нового файла».
2. Введите `created_in_mcedit.txt` и подтвердите.
3. Введите текст, сохраните (`F2`), выйдите (`F10`).
4. Убедитесь, что файл появился на панели.

### 7.5. Сравнение файлов

1. Выделите `file1.txt` на левой панели.
2. Через меню `F9 → Command → Compare directories` или `F9 → Command → Compare files…` сравните два файла.
3. Изучите подсветку различий.

## 8. Задание 7. Поиск файлов в `mc`

### 8.1. Поиск по имени

1. Нажмите `F9 → Command → Find file` (или `Alt + ?`).
2. В поле «Filename» введите `*.txt`.
3. В поле «Start at» укажите `~/mc_lab`.
4. Нажмите `Enter` или `F1` / кнопку «Start» — начнётся поиск.

### 8.2. Поиск по содержимому

В том же диалоге переключитесь на вкладку «Content» и введите строку `Содержимое`. Запустите поиск.

### 8.3. Действия с найденными файлами

В окне результатов выделите найденный файл и:
- `F3` — просмотр;
- `F4` — редактирование;
- `F5` — копировать;
- `F8` — удалить;
- `F9` — перейти к файлу на панели.

## 9. Задание 8. Работа с архивами через `mc`

`mc` умеет «входить» в архивы как в каталоги.

### 9.1. Создание архива

1. На левой панели выделите `file1.txt` и `file2.txt`.
2. Нажмите `F9 → File → Compress…` (или `Alt + C` в некоторых версиях — через меню).
3. Выберите формат `tar.gz` (или `.zip`).
4. Укажите путь к архиву, например `~/mc_lab/archive/files.tar.gz`.
5. Подтвердите.

### 9.2. Просмотр содержимого архива

1. На правой панели перейдите в `~/mc_lab/archive`.
2. Выделите `files.tar.gz` и нажмите `Enter` — `mc` откроет архив как каталог, показав его содержимое.
3. Внутри архива можно просматривать файлы (`F3`) и даже извлекать их (`F5`).

### 9.3. Извлечение из архива

1. Войдите в архив (`Enter`).
2. Выделите нужный файл и нажмите `F5`.
3. Укажите путь для извлечения (например, `~/mc_lab/dest`). Файл будет распакован.

### 9.4. Выход из архива

`Backspace` или `Ctrl + PgUp` — вернуться на уровень выше, к самому архиву.

## 10. Задание 9. Работа с командной строкой `mc`

Внизу экрана `mc` есть командная строка. В ней можно выполнять обычные команды Bash, не выходя из `mc`.

1. Нажмите `Ctrl + O` — панели скрываются, вы попадаете в полноценный shell с текущим каталогом активной панели. Вернуться в `mc` — снова `Ctrl + O`.
2. В командной строке `mc` (когда панели видны) наберите `pwd` и `Enter` — команда выполнится.
3. Наберите `ls -la` и `Enter`.

## 11. Задание 10. Настройка `mc`

Откройте меню настроек: `F9 → Options → Configuration`.

Изучите и, при необходимости, измените:
- показ скрытых файлов по умолчанию (`Show hidden files`);
- панель «Quick view» (`Use SI units for file sizes`);
- поведение подтверждений удаления (`Confirm delete`);
- редактор по умолчанию (`Use internal edit`).

Настройки сохраняются в `~/.config/mc/ini`. Проверьте файл:

```bash
cat ~/.config/mc/ini
```

Также настройки `mcedit` хранятся в `~/.config/mc/mcedit/` или через меню `F9 → Options → Editor`.
