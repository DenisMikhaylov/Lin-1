# Лабораторная работа
## Текстовые редакторы в командной строке Debian 12: `nano`, `vim`, `mcedit`

**Цель работы:** освоить базовые приёмы работы в трёх текстовых редакторах командной строки Debian 12 — `nano`, `vim` и `mcedit` — и научиться выбирать подходящий редактор для разных задач.

**Среда выполнения:** Debian 12, пользователь `debian` с правами `sudo`, терминал.

**Продолжительность:** 1 академический час.

---

## 1. Теоретические сведения

Текстовые редакторы в Linux делятся на две категории:

- **Модальные** — `vim` (и его предок `vi`). Редактирование происходит в разных режимах: командный, вставки, визуальный, командной строки. Мощный, но требует привыкания.
- **Немодальные** — `nano`, `mcedit`. Работают по принципу «что видишь, то и редактируешь». Проще для новичков, но менее гибкие.

**Краткое сравнение:**

| Характеристика | `nano` | `vim` | `mcedit` |
|---|---|---|---|
| Режимы | Немодальный | Модальный | Немодальный |
| Порог входа | Низкий | Высокий | Низкий |
| Подсветка синтаксиса | Ограниченная | Обширная | Есть |
| Расширяемость | Минимальная | Огромная (плагины, скрипты) | Средняя |
| Наличие в минимальной установке | Обычно да | Обычно да | Требует `mc` |
| Подходит для правки конфигов | Да | Да | Да |
| Подходит для программирования | Ограниченно | Да | Ограниченно |

**Что нужно знать перед началом:**
- `mcedit` входит в пакет **Midnight Commander** (`mc`). Если его нет — установите: `sudo apt install -y mc`.
- `vim` в Debian 12 по умолчанию может быть установлен как `vim-tiny` (урезанная версия). Полная версия: `sudo apt install -y vim`.
- `nano` обычно предустановлен. Если нет: `sudo apt install -y nano`.

**Проверка наличия редакторов:**
```bash
which nano
which vim
which mcedit
```

## 3. Задание 2. Редактор `nano`

### 3.1. Открытие файла и базовое редактирование

```bash
nano nano_test.txt
```

Введите несколько строк текста, например:

```
Первая строка в nano
Вторая строка
Третья строка
```

### 3.2. Основные горячие клавиши `nano`

Обратите внимание на нижнюю панель подсказок. Символ `^` означает `Ctrl`.

| Клавиши | Действие |
|---|---|
| `Ctrl + O` | Сохранить файл (Write Out) |
| `Enter` | Подтвердить имя файла |
| `Ctrl + X` | Выйти |
| `Ctrl + K` | Вырезать текущую строку |
| `Ctrl + U` | Вставить вырезанное |
| `Ctrl + W` | Поиск |
| `Ctrl + \` | Замена |
| `Ctrl + G` | Справка |
| `Ctrl + C` | Показать позицию курсора |
| `Ctrl + _` | Перейти к строке/столбцу |
| `Alt + U` | Отменить последнее действие |
| `Alt + E` | Повторить отменённое |
| `Ctrl + A` | В начало строки |
| `Ctrl + E` | В конец строки |

### 3.3. Практика в `nano`

1. Перейдите в конец файла (`Alt + /` или `Ctrl + End`).
2. Добавьте строку `Четвёртая строка`.
3. Найдите строку `Вторая` через `Ctrl + W`.
4. Замените `nano` на `Nano` через `Ctrl + \`.
5. Сохраните файл (`Ctrl + O`, `Enter`) и выйдите (`Ctrl + X`).

Проверьте результат:
```bash
cat nano_test.txt
```

### 3.4. Полезные параметры запуска

```bash
nano -l nano_test.txt     # показать номера строк
nano -w nano_test.txt     # не переносить длинные строки
nano -v nano_test.txt     # режим только для чтения
nano +3 nano_test.txt     # открыть на строке 3
```

### 3.5. Настройка `nano` через `~/.nanorc`

```bash
echo 'set linenumbers' >> ~/.nanorc
echo 'set autoindent' >> ~/.nanorc
echo 'set tabsize 4' >> ~/.nanorc
nano nano_test.txt
```
Убедитесь, что номера строк появились.

## 4. Задание 3. Редактор `vim`

### 4.1. Режимы `vim`

`vim` — модальный редактор. Основные режимы:

- **Normal (командный)** — режим по умолчанию. Перемещение по тексту, удаление, копирование, вставка.
- **Insert (вставки)** — ввод текста. Вход: `i`, `a`, `o`, `I`, `A`, `O`.
- **Visual (визуальный)** — выделение текста. Вход: `v`, `V`, `Ctrl + V`.
- **Command-line (командной строки)** — ввод команд `:`. Вход: `:`.

Выход в Normal из любого режима — клавиша `Esc`.

### 4.2. Открытие файла

```bash
vim vim_test.txt
```

При первом запуске, возможно, потребуется установить полную версию:
```bash
sudo apt install -y vim
```

### 4.3. Ввод текста

1. Нажмите `i` — вы в режиме вставки (внизу появится `-- INSERT --`).
2. Введите строки:
```
Первая строка в vim
Вторая строка
Третья строка
```
3. Нажмите `Esc` — вернулись в Normal.

### 4.4. Сохранение и выход

В Normal нажмите `:` и введите:

| Команда | Действие |
|---|---|
| `:w` | Сохранить |
| `:q` | Выйти (если нет изменений) |
| `:wq` или `:x` | Сохранить и выйти |
| `:q!` | Выйти без сохранения |
| `:w имя_файла` | Сохранить под новым именем |

### 4.5. Основные команды `vim` в Normal-режиме

**Перемещение:**

| Клавиши | Действие |
|---|---|
| `h`, `j`, `k`, `l` | Влево, вниз, вверх, вправо |
| `w`, `b` | К следующему/предыдущему слову |
| `0`, `$` | В начало/конец строки |
| `gg`, `G` | В начало/конец файла |
| `:<число>` | Перейти к строке |
| `Ctrl + F`, `Ctrl + B` | Страница вперёд/назад |

**Редактирование:**

| Клавиши | Действие |
|---|---|
| `i`, `a` | Вставка до/после курсора |
| `o`, `O` | Новая строка ниже/выше |
| `x`, `X` | Удалить символ под/перед курсором |
| `dd`, `yy`, `p` | Удалить/скопировать строку/вставить |
| `dw`, `cw` | Удалить/заменить слово |
| `u` | Отменить |
| `Ctrl + R` | Повторить отменённое |
| `.` | Повторить последнее действие |

**Поиск и замена:**

| Команда | Действие |
|---|---|
| `/шаблон` | Поиск вперёд |
| `?шаблон` | Поиск назад |
| `n`, `N` | Следующее/предыдущее совпадение |
| `:%s/старое/новое/g` | Заменить во всём файле |
| `:s/старое/новое/g` | Заменить в текущей строке |

**Визуальный режим:**

| Клавиши | Действие |
|---|---|
| `v` | Символьное выделение |
| `V` | Построчное выделение |
| `Ctrl + V` | Блочное выделение |
| `d`, `y`, `c` | Удалить/скопировать/заменить выделенное |

### 4.6. Практика в `vim`

1. Откройте файл и войдите в режим вставки (`i`), введите три строки, выйдите (`Esc`).
2. Перейдите в конец файла (`G`), добавьте новую строку (`o`), введите текст, вернитесь в Normal (`Esc`).
3. Перейдите к строке 2 (`:2`), удалите её (`dd`).
4. Отмените удаление (`u`).
5. Найдите слово `Вторая` (`/Вторая`).
6. Замените все `vim` на `Vim` (`:%s/vim/Vim/g`).
7. Сохраните и выйдите (`:wq`).

Проверьте результат:
```bash
cat vim_test.txt
```

### 4.7. Полезные параметры запуска

```bash
vim +3 vim_test.txt       # открыть на строке 3
vim -R vim_test.txt       # режим только для чтения
vim -c "set number" file  # выполнить команду при запуске
```

### 4.8. Настройка `vim` через `~/.vimrc`

Создайте файл:
```bash
cat > ~/.vimrc <<EOF
set number
set autoindent
set tabstop=4
set shiftwidth=4
set expandtab
set hlsearch
syntax on
EOF
```
Откройте `vim` снова и убедитесь, что номера строк включены и подсветка синтаксиса работает.

## 5. Задание 4. Редактор `mcedit`

### 5.1. Установка (если не установлен)

```bash
sudo apt install -y mc
```

### 5.2. Запуск `mcedit` напрямую

```bash
mcedit mcedit_test.txt
```

`mcedit` — встроенный редактор Midnight Commander, но его можно запускать и отдельно.

### 5.3. Интерфейс и базовые клавиши

Внизу экрана расположена панель функциональных клавиш. Обратите внимание: в некоторых терминалах `F-клавиши` перехватываются, поэтому используйте `Esc + цифра` (например, `Esc + 2` для F2).

| Клавиши | Действие |
|---|---|
| `F2` | Сохранить |
| `F10` | Выйти |
| `F3` | Начать выделение |
| `F4` | Поиск |
| `F5` | Копировать выделенное |
| `F6` | Переместить выделенное |
| `F7` | Поиск (в некоторых версиях) |
| `F8` | Удалить строку |
| `F9` | Меню |
| `Ctrl + Y` | Удалить строку |
| `Ctrl + U` | Отменить |
| `Ctrl + O` | Открыть файл |
| `Alt + F` | Меню File |
| `Esc`, затем цифра | Альтернатива F-клавишам |

### 5.4. Практика в `mcedit`

1. Введите текст:
```
Первая строка в mcedit
Вторая строка
Третья строка
```
2. Сохраните файл (`F2`).
3. Перейдите в конец файла (`Ctrl + End`).
4. Найдите слово `Вторая` (`F4` или `F7`).
5. Выделите строку и удалите её (`Ctrl + Y`).
6. Отмените удаление (`Ctrl + U`).
7. Сохраните и выйдите (`F2`, затем `F10`).

Проверьте результат:
```bash
cat mcedit_test.txt
```

### 5.5. Встроенный Midnight Commander

`mcedit` можно использовать через файловый менеджер `mc`:

```bash
mc
```

В `mc`:
- `F4` — открыть файл в `mcedit`;
- `F3` — просмотр файла;
- `F7` — создать каталог;
- `F8` — удалить файл/каталог;
- `F5` — копировать;
- `F6` — переместить;
- `F10` — выход.

Откройте `mcedit_test.txt` через `F4`, отредактируйте, сохраните и выйдите.

### 5.6. Настройка `mcedit`

Через меню `F9 → Options → General` можно настроить:
- размер табуляции;
- показ номеров строк;
- режим сохранения резервных копий;
- синтаксическую подсветку.

Также можно отредактировать файл `~/.config/mc/ini` вручную.
