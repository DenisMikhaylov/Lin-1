# Лабораторная работа
## Работа с файлами и текстом в командной строке Debian 12

**Цель работы:** освоить полный набор операций с файлами и каталогами в командной строке Debian 12: создание, просмотр, редактирование, копирование, перемещение, переименование, удаление, изменение прав и владельцев, поиск файлов и фильтрацию текста.

**Среда выполнения:** Debian 12, пользователь `debian` с правами `sudo`, терминал.

**Продолжительность:** 2 академических часа.

## 1. Теоретические сведения

В Linux всё является файлом: обычные файлы, каталоги, устройства, сокеты, символические ссылки. Работа с ними ведётся через команды оболочки.

**Ключевые понятия:**
- **Путь** — абсолютный (начинается с `/`) или относительный (от текущего каталога).
- **`.`** — текущий каталог, **`..`** — родительский, **`~`** — домашний каталог пользователя.
- **inode** — структура, хранящая метаданные файла (права, владелец, время, указатели на блоки).
- **Жёсткая ссылка (hard link)** — второе имя для того же inode.
- **Символическая ссылка (symlink)** — файл, содержащий путь к другому файлу.
- **Права доступа** — `r`, `w`, `x` для владельца, группы и остальных.
- **Фильтрация текста** — извлечение нужных строк и полей из текстовых файлов.

## 5. Задание 4. Редактирование файлов

### 5.1. Редактор `nano`

```bash
nano file3.log
```
Добавьте несколько строк, сохраните (`Ctrl+O`, `Enter`) и выйдите (`Ctrl+X`).

### 5.2. Редактор `vim` (базовые команды)

```bash
vim file2.txt
```
Внутри: `i` — режим вставки, `Esc` — выход из вставки, `:w` — сохранить, `:q` — выйти, `:wq` — сохранить и выйти, `:q!` — выйти без сохранения.

### 5.3. Редактирование без интерактивного редактора

```bash
sed -i 's/Первая/1-я/' file1.txt
cat file1.txt
```

### 5.4. Смена редактора по умолчанию

```bash
sudo update-alternatives --config editor
echo 'export EDITOR=nano' >> ~/.bashrc
source ~/.bashrc
```

```bash
ls -R
```

Копирование по маске:

## 10. Задание 9. Права доступа и владельцы

```bash
touch perm.txt
ls -l perm.txt
chmod 755 perm.txt
chmod u+x perm.txt
chmod g-w perm.txt
chmod o=r perm.txt
ls -l perm.txt

chmod -R 750 dir1
ls -lR dir1 | head -20
```

Владельцы (требует `sudo`):

```bash
sudo chown debian:debian perm.txt
sudo chown -R debian:debian dir1
sudo chgrp debian perm.txt
ls -l perm.txt
```

Специальные биты:

```bash
chmod u+s script.sh         # SUID
chmod g+s dir1              # SGID
chmod +t dir1               # Sticky bit
ls -ld dir1
```

## 11. Задание 10. Поиск файлов

### 11.1. `find` по имени

```bash
find /etc -maxdepth 1 -name "*.conf"
find ~ -name "*.txt"
find / -name "sshd_config" 2>/dev/null
find / -iname "README*" 2>/dev/null | head
```

### 11.2. `find` по типу, размеру, времени

```bash
find /etc -type d | head
find /etc -type f -size +1M | head
find /var/log -type f -mtime -1
find / -type f -mmin -10 2>/dev/null | head
```

### 11.3. `find` с выполнением действия

```bash
find ~ -name "*.txt" -exec ls -l {} \;
find ~ -name "*.log" -delete
find /etc -name "*.conf" -exec grep -l "include" {} \; 2>/dev/null | head
```

### 11.4. `locate` (быстрый поиск по базе)

```bash
sudo apt install -y mlocate
sudo updatedb
locate sshd_config
locate -b "\passwd"
```

### 11.5. Поиск по содержимому (`grep`)

```bash
grep "root" /etc/passwd
grep -i "debian" /etc/passwd
grep -v "nologin" /etc/passwd
grep -c "bash" /etc/passwd
grep -r "PermitRootLogin" /etc/ssh/ 2>/dev/null
```

### 11.6. `which`, `whereis`, `type`

```bash
which ls
whereis ls
type ls
command -v ls
```

## 12. Задание 11. Фильтрация и обработка текста

Создайте тестовый файл:

```bash
cat > data.txt <<EOF
alice:30:Moscow
bob:25:London
carol:35:Berlin
dave:28:Moscow
eve:22:Paris
EOF
```

### 12.1. `grep` — фильтрация строк

```bash
grep "Moscow" data.txt
grep -v "Moscow" data.txt
grep -E "Moscow|Paris" data.txt
grep -o "[A-Z][a-z]*" data.txt
```

### 12.2. `cut` — извлечение полей

```bash
cut -d: -f1 data.txt
cut -d: -f1,3 data.txt
cut -d: -f2- data.txt
```

### 12.3. `sort` — сортировка

```bash
sort data.txt
sort -t: -k2 -n data.txt
sort -t: -k2 -n -r data.txt
sort -u data.txt
```

### 12.4. `uniq` — уникальные строки

```bash
cut -d: -f3 data.txt | sort | uniq
cut -d: -f3 data.txt | sort | uniq -c
cut -d: -f3 data.txt | sort | uniq -d
```

### 12.5. `tr` — замена и удаление символов

```bash
echo "Hello World" | tr 'a-z' 'A-Z'
tr ':' ' ' < data.txt
tr -d 'aeiou' < data.txt
```

### 12.6. `sed` — потоковый редактор

```bash
sed 's/Moscow/MSK/' data.txt
sed -n '2,4p' data.txt
sed '/bob/d' data.txt
sed -i 's/London/LDN/' data.txt
```

### 12.7. `awk` — обработка по полям

```bash
awk -F: '{print $1}' data.txt
awk -F: '$2 > 28 {print $1, $2}' data.txt
awk -F: '{sum+=$2} END {print "Средний возраст:", sum/NR}' data.txt
awk -F: '{print $1" из "$3}' data.txt
```

### 12.8. `column` — оформление таблицы

```bash
column -t -s: data.txt
```
