# Лабораторная работа
## Установка Debian 12 в VirtualBox и развёртывание Snort 3 из исходников

**Цель работы:** получить практические навыки скачивания дистрибутива Debian 12, создания виртуальной машины в Oracle VM VirtualBox, установки операционной системы, базовой настройки сети и учётной записи, а также сборки и конфигурирования системы обнаружения вторжений Snort 3.

**Сервер:** `gate`  
**Учётная запись:** `debian` / пароль `debian`  
**Гипервизор:** Oracle VM VirtualBox 7.x  
**Время выполнения:** 3–4 академических часа.

---

## 1. Исходные данные и требования

- Персональный компьютер с доступом в интернет.
- Установленный **Oracle VM VirtualBox** версии 7.0 или новее (скачать: https://www.virtualbox.org/wiki/Downloads).
- **VirtualBox Extension Pack** (опционально, но рекомендуется — добавляет поддержку USB 2.0/3.0, RDP и шифрования).
- Минимум **4 ГБ оперативной памяти** хоста, свободных для виртуальной машины (рекомендуется 8 ГБ).
- **25 ГБ свободного дискового пространства** на хосте.
- Процессор с поддержкой аппаратной виртуализации (VT-x для Intel, AMD-V для AMD). В BIOS/UEFI должна быть включена опция виртуализации.
- Базовые навыки работы в командной строке Linux.

> Все дальнейшие команды внутри ВМ выполняются от пользователя `debian`. Если `sudo` не настроен, используйте `su -` для переключения в root.

---

## 2. Задание

1. Скачать установочный ISO-образ Debian 12.
2. Создать виртуальную машину в VirtualBox.
3. Установить Debian 12 с именем хоста `gate` и пользователем `debian`.
4. Настроить сеть виртуальной машины в VirtualBox.
5. Обновить систему и установить зависимости для сборки Snort 3.
6. Собрать и установить библиотеку LibDAQ.
7. Собрать и установить Snort 3 из исходников.
8. Настроить конфигурацию `snort.lua` и локальное правило.
9. Создать systemd-сервис и проверить работу IDS.
10. Оформить отчёт.

## 3. Порядок выполнения

### 3.1. Скачивание дистрибутива Debian 12

Официальная страница загрузки Debian: **https://www.debian.org/distrib/**.



**Прямая ссылка на актуальный образ (пример):**
```
https://get.debian.org/mirror/cdimage/archive/12.12.0/amd64/iso-dvd/
```
> Номер версии (12.x.x) может меняться. Всегда проверяйте актуальную ссылку на официальном сайте.


---

### 3.2. Создание виртуальной машины в VirtualBox

1. Запустите **Oracle VM VirtualBox**.
2. Нажмите кнопку **«Создать»** (или `Машина → Создать`).
3. Заполните параметры мастера:

   **Шаг 1. Имя и операционная система**
   - Имя: `gate`
   - Папка: оставьте по умолчанию (или укажите свой путь)
   - ISO-образ: нажмите на иконку папки и выберите скачанный `debian-12.*-amd64-netinst.iso`
   - Тип: `Linux`
   - Версия: `Debian (64-bit)`
   - Поставьте галочку **«Пропустить автоматическую установку»** (Skip Unattended Installation), если она появилась — мы будем устанавливать вручную.

   **Шаг 2. Оборудование**
   - Основная память (RAM): **4096 МБ** (минимум 2048 МБ, рекомендуется 4096–8192 МБ)
   - Процессоры: **2** (минимум; если хост позволяет — 4)

   **Шаг 3. Виртуальный жёсткий диск**
   - Выберите **«Создать новый виртуальный жёсткий диск»**
   - Тип файла: `VDI (VirtualBox Disk Image)`
   - Хранение: **«Динамический виртуальный жёсткий диск»**
   - Размер: **25 ГБ** (минимум 20 ГБ)
   - Имя файла: `gate.vdi` (по умолчанию)

4. Нажмите **«Готово»**.

5. **Настройка сети (обязательно до первого запуска):**
   - Выделите ВМ `gate` в списке слева и нажмите **«Настроить»** (или `Машина → Настроить`).
   - Перейдите в раздел **«Сеть»**.
   - Адаптер 1:
     - Поставьте галочку **«Включить сетевой адаптер»**.
     - Тип подключения: **«Bridge»** (рекомендуется для доступа в интернет; ).
      - Если нужен доступ к ВМ с хоста по SSH, добавьте **Адаптер 2**:
     - Тип подключения: **«Сетевой мост»** (Bridged Adapter) или **«Внутренняя сеть»** (Internal Network).
   - Нажмите **«ОК»**.

---

### 3.3. Установка Debian 12

Запустите виртуальную машину кнопкой **«Запустить»**. Откроется окно консоли VirtualBox, и начнётся загрузка с ISO-образа.

1. В меню загрузчика выберите **`Install`** (не `Graphical install`, чтобы избежать проблем с видеодрайвером в VirtualBox) и нажмите Enter.
2. **Выбор языка.** Выберите язык (например, `English` или `Russian`).
3. **Выбор местоположения.** Укажите вашу страну.
4. **Раскладка клавиатуры.** Выберите `American English` (или свою).
5. **Настройка сети:**
   - Имя хоста: `gate`
   - Доменное имя: оставьте пустым.
6. **Пользователь root.** Оставьте поле пароля root **пустым** — тогда пользователь `debian` получит права через `sudo` (пакет `sudo` установится автоматически).
7. **Создание пользователя:**
   - Полное имя: `debian`
   - Имя пользователя: `debian`
   - Пароль: `debian` (подтвердите).
8. **Часовой пояс.** Укажите свой регион.
9. **Разметка диска:**
   - Выберите **«Guided — use entire disk»**.
   - Выберите диск (он будет один — `/dev/sda`).
   - Схема: **«All files in one partition»** (для учебной ВМ это проще всего).
   - Подтвердите запись изменений на диск: **«Yes»**.
10. **Установка базовой системы.** Дождитесь завершения.
11. **Настройка менеджера пакетов:**
    - Страна зеркала: выберите свой регион (или `deb.debian.org`).
    - Прокси: оставьте пустым.
12. **Участие в опросе popularity-contest.** Выберите **«No»**.
13. **Выбор программного обеспечения.**
    - Снимите галочки со всех пунктов, кроме:
      - ☑ **`SSH server`**
      - ☑ **`standard system utilities`**
    - **НЕ** выбирайте графическое окружение (GNOME, Xfce и т.д.) — для сервера оно не нужно и только расходует ресурсы.
14. **Установка загрузчика GRUB.**
    - Согласитесь установить GRUB в главную загрузочную запись: **«Yes»**.
    - Устройство: выберите `/dev/sda`.
15. **Завершение установки.**
    - Когда появится сообщение «Installation complete», нажмите **«Continue»**.
    - ВМ перезагрузится. Если появится сообщение о невозможности извлечь ISO, откройте меню VirtualBox **`Устройства → Оптические диски → Извлечь диск`** (или нажмите `Host + D`, где `Host` — правый Ctrl по умолчанию).
    - Нажмите Enter для продолжения загрузки.

После загрузки вы увидите консольный вход Debian. Войдите:
- Логин: `debian`
- Пароль: `debian`

---

### 3.4. Первичная настройка системы

Обновите систему и убедитесь, что `sudo` работает:

```bash
sudo apt update && sudo apt upgrade -y
sudo whoami
```
Команда должна вывести `root`.

Убедитесь, что имя хоста установлено верно:

```bash
hostnamectl set-hostname gate
hostname
```
Должно вывести `gate`.

**Проверка сети в VirtualBox NAT.** Убедитесь, что ВМ имеет доступ в интернет:

```bash
ip -br addr        # IP-адрес обычно 10.0.2.15 (NAT по умолчанию)
ping -c 4 deb.debian.org
```
Если пинг не проходит, проверьте настройки адаптера в VirtualBox (`Настроить → Сеть → Адаптер 1 → Тип подключения: NAT`).

Определите сетевой интерфейс (в VirtualBox с virtio-net обычно это `enp0s3`):

```bash
ip -br link
```
Запомните имя интерфейса. В дальнейшем заменяйте `<INTERFACE>` на него.
