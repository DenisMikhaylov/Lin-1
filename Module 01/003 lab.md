# Лабораторная работа
## Поиск помощи по командам в Debian 12: `man`, `--help`, `help`, `info`

**Цель работы:** освоить основные инструменты получения справочной информации о командах в Debian 12 и научиться быстро находить нужные параметры и примеры использования.

**Среда выполнения:** Debian 12, пользователь `debian`, терминал.

**Продолжительность:** 1 академический час.

---

## 1. Теоретические сведения

В Debian 12 справочная информация о командах доступна через несколько механизмов:

| Инструмент | Для чего используется |
|---|---|
| `man` | Полные руководства (manual pages) по командам, файлам, системным вызовам |
| `--help` | Краткая справка, встроенная в большинство внешних команд |
| `help` | Справка по встроенным командам Bash (`cd`, `echo`, `alias` и др.) |
| `info` | Подробные руководства GNU-проекта в формате Texinfo |
| `man -k` / `apropos` | Поиск по ключевому слову в описаниях man-страниц |
| `whatis` | Краткое описание команды из базы man |

**Разделы man-страниц:**

| Раздел | Содержимое |
|---|---|
| 1 | Пользовательские команды |
| 2 | Системные вызовы |
| 3 | Библиотечные функции |
| 4 | Специальные файлы (`/dev`) |
| 5 | Форматы файлов и соглашения |
| 6 | Игры |
| 7 | Разное (макросы, стандарты) |
| 8 | Административные команды |

## 2. Задание 1. Работа с `man`

### 2.1. Открытие и навигация

Откройте man-страницу команды `ls`:
```bash
man ls
```

Изучите навигацию:
- `↑` / `↓` или `PgUp` / `PgDn` — прокрутка;
- `Space` — следующая страница;
- `b` — предыдущая страница;
- `g` — в начало;
- `G` — в конец;
- `/шаблон` — поиск вперёд;
- `?шаблон` — поиск назад;
- `n` — следующее совпадение;
- `N` — предыдущее совпадение;
- `q` — выход.

### 2.2. Поиск по ключевому слову

```bash
man -k copy
apropos copy
man -k "list directory"
```

### 2.3. Краткое описание команды

```bash
whatis ls
whatis cp
whatis grep
```

### 2.4. Выбор раздела man

```bash
man 1 printf
man 3 printf
```

### 2.5. Поиск внутри man-страницы

Откройте `man tar`, найдите параметр `--exclude` через `/--exclude`, затем выйдите через `q`.

### 2.6. Сохранение man-страницы в файл

```bash
man ls | col -b > /tmp/ls_man.txt
head -20 /tmp/ls_man.txt
```

## 3. Задание 2. Использование `--help`

Многие внешние команды поддерживают краткую справку через `--help` или `-h`.

```bash
ls --help
cp --help
grep --help
tar --help
ip --help
ss --help
```

Сравните объём вывода `ls --help` и `man ls`. Обратите внимание, что `--help` обычно короче и содержит только основные параметры.

Проверьте, что произойдёт при вызове команды без параметров:
```bash
cp
grep
```

Многие команды в этом случае выводят краткую подсказку по использованию.

## 4. Задание 3. Использование `help` для встроенных команд Bash

Встроенные команды Bash не имеют отдельных исполняемых файлов, поэтому для них используется `help`.

```bash
help
help cd
help echo
help alias
help export
help read
```

Получите список всех встроенных команд:
```bash
help
compgen -b
enable -a
```

Сравните:
```bash
type cd
type ls
type echo
type if
```

Для встроенных команд `type` покажет `builtin`, для внешних — путь к исполняемому файлу.

## 5. Задание 4. Использование `info`

`info` — более подробное руководство для GNU-утилит.

```bash
info ls
info cp
info coreutils
```

Навигация в `info`:
- `Space` — следующая страница;
- `Backspace` / `Del` — предыдущая;
- `n` — следующий узел;
- `p` — предыдущий узел;
- `u` — вверх;
- `l` — назад по истории;
- `q` — выход;
- `Ctrl + G` — отмена.

Если `info` не установлен:
```bash
sudo apt install -y info
```

## 6. Задание 5. Сравнение инструментов

Для команды `grep` получите справку четырьмя способами:
```bash
man grep
grep --help
info grep
help grep 2>/dev/null || echo "grep не является встроенной командой Bash"
```

Для встроенной команды `echo`:
```bash
help echo
man echo
echo --help
```

Сделайте вывод: какой инструмент удобнее для встроенных команд, а какой — для внешних.

## 10. Приложение. Шпаргалка

| Действие | Команда |
|---|---|
| Открыть man-страницу | `man <команда>` |
| Man по разделу | `man <номер> <команда>` |
| Поиск по описаниям | `man -k <слово>`, `apropos <слово>` |
| Краткое описание | `whatis <команда>` |
| Поиск в man | `/шаблон`, `?шаблон`, `n`, `N` |
| Выход из man | `q` |
| Справка внешней команды | `<команда> --help` |
| Справка встроенной команды Bash | `help <команда>` |
| Список встроенных команд | `help`, `compgen -b` |
| GNU-руководство | `info <команда>` |
| Выход из info | `q` |
| Определить тип команды | `type <команда>` |
