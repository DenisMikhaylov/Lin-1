# Лабораторная работа
## Основы командной строки в Debian 12

**Цель работы:** освоить базовые приёмы работы в командной оболочке Bash: настройку строки приветствия, создание алиасов, использование горячих клавиш, встроенных команд, переменных и переменных окружения, шаблонов подстановки, экранирования, перенаправления потоков ввода-вывода и конвейеров.

**Среда выполнения:** виртуальная машина с Debian 12, пользователь `debian` с правами `sudo`, терминал (консоль или SSH).

**Продолжительность:** 2 академических часа.

---

## 1. Теоретические сведения

**Bash** — командная оболочка (shell), которая принимает команды пользователя, интерпретирует их и передаёт на выполнение ядру или внешним программам. Bash поддерживает переменные, алиасы, шаблоны, перенаправления, конвейеры и множество встроенных команд.

**Ключевые понятия:**
- **Переменная оболочки** — именованное значение, доступное в текущем экземпляре Bash.
- **Переменная окружения** — переменная, экспортированная в окружение и доступная дочерним процессам.
- **Потоки:** `stdin` (дескриптор 0), `stdout` (1), `stderr` (2).
- **Конвейер (`|`)** — передача `stdout` одной команды на `stdin` другой.
- **Шаблоны подстановки (globbing)** — символы `*`, `?`, `[...]`, `{...}`, которые оболочка раскрывает в имена файлов до выполнения команды.
- **Экранирование** — способы защитить специальные символы от интерпретации оболочкой.

## 2. Задание 1. Изменение строки приветствия и сохранение результата

Строка приветствия может отображаться:
- до входа в систему — файл `/etc/issue`;
- после входа — файл `/etc/motd` (Message of the Day);
- в приглашении командной строки — переменная `PS1`.

### 2.1. Системное приветствие через `/etc/motd`

Проверьте текущий файл:
```bash
ls -l /etc/motd
cat /etc/motd
```
> В Debian 12 `/etc/motd` может быть символической ссылкой. Если это так, удалите ссылку и создайте обычный файл:
> ```bash
> sudo rm /etc/motd
> sudo touch /etc/motd
> ```

Отредактируйте файл:
```bash
sudo nano /etc/motd
```
Добавьте строку, например:
```
Добро пожаловать на сервер gate!
```
Сохраните файл. Проверьте, что изменения применились после повторного входа:
```bash
exit
# войдите снова под debian
cat /etc/motd
```

### 2.2. Персональное приветствие для пользователя `debian`

Добавьте вывод приветствия в `~/.bashrc`:
```bash
echo 'echo "Здравствуйте, $USER! Вы вошли на $(hostname)."' >> ~/.bashrc
source ~/.bashrc
```
Убедитесь, что строка появилась:
```bash
tail -n 3 ~/.bashrc
```

### 2.3. Изменение приглашения командной строки (`PS1`)

Добавьте в `~/.bashrc` настройку `PS1`, например:
```bash
echo 'PS1="\[\e[1;32m\]\u@\h\[\e[0m\]:\w\$ "' >> ~/.bashrc
source ~/.bashrc
```
Проверьте, что приглашение изменилось. Сохраните файл — настройка будет действовать при каждом новом входе.

## 3. Задание 2. Алиасы для всех пользователей и для конкретного пользователя

**Алиас** — псевдоним команды. Алиасы работают в интерактивных оболочках Bash.

### 3.1. Алиасы для всех пользователей

Создайте файл в `/etc/profile.d/`:
```bash
sudo nano /etc/profile.d/lab_aliases.sh
```
Добавьте:
```bash
alias ll='ls -alF'
alias grep='grep --color=auto'
alias ..='cd ..'
```
Сохраните. Проверьте, что файл исполняется при новом входе:
```bash
exit
# войдите снова
alias ll
```

### 3.2. Алиасы для конкретного пользователя

Добавьте алиасы в `~/.bashrc` пользователя `debian`:
```bash
echo "alias myip='ip -br addr'" >> ~/.bashrc
echo "alias ports='ss -tulpn'" >> ~/.bashrc
source ~/.bashrc
alias
```
Проверьте работу:
```bash
myip
ports
```

### 3.3. Просмотр и удаление алиасов

```bash
alias
type ll
unalias myip
alias
```

> **Примечание.** Алиасы не раскрываются в неинтерактивных скриптах. Для скриптов используйте функции или отдельные исполняемые файлы.

## 4. Задание 3. Быстрые клавиши в командной строке

Ознакомьтесь с основными сочетаниями клавиш Bash и проверьте их на практике.

| Сочетание | Действие |
|---|---|
| `Tab` | Автодополнение команд, файлов, каталогов |
| `Ctrl + A` | Перейти в начало строки |
| `Ctrl + E` | Перейти в конец строки |
| `Ctrl + U` | Удалить текст от курсора до начала строки |
| `Ctrl + K` | Удалить текст от курсора до конца строки |
| `Ctrl + W` | Удалить слово перед курсором |
| `Ctrl + R` | Поиск по истории команд (обратный) |
| `Ctrl + L` | Очистить экран |
| `Ctrl + C` | Прервать текущую команду |
| `Ctrl + D` | Завершить ввод (EOF) или выйти из оболочки |
| `Alt + .` | Вставить последний аргумент предыдущей команды |
| `!!` | Повторить последнюю команду |
| `!$` | Последний аргумент предыдущей команды |
| `!n` | Выполнить команду с номером `n` из истории |
| `history` | Показать историю команд |

**Практика:**
1. Наберите `ls /usr/sha` и нажмите `Tab`.
2. Выполните `echo one two three`, затем `echo !$`.
3. Нажмите `Ctrl + R`, начните вводить `ping`, найдите нужную команду.
4. Выполните `ls -l /etc` и затем `!!`.

## 6. Задание 5. Переменные в Bash

### 6.1. Создание и использование переменных

```bash
NAME="Debian"
echo $NAME
echo "Привет, $NAME"
echo "Привет, ${NAME}12"
```
Обратите внимание: в присваивании **нельзя** ставить пробелы вокруг `=`.

### 6.2. Локальные и экспортируемые переменные

```bash
LOCAL_VAR="local"
export GLOBAL_VAR="global"
bash -c 'echo "LOCAL_VAR=$LOCAL_VAR"'
bash -c 'echo "GLOBAL_VAR=$GLOBAL_VAR"'
```
`LOCAL_VAR` не передаётся в дочерний процесс, а `GLOBAL_VAR` — передаётся.

### 6.3. Удаление и защита переменной

```bash
unset LOCAL_VAR
readonly READONLY_VAR="const"
READONLY_VAR="new"   # ошибка
```

### 6.4. Специальные переменные

```bash
echo "Имя оболочки: $0"
echo "Количество аргументов: $#"
echo "Код возврата последней команды: $?"
echo "PID текущей оболочки: $$"
```

### 6.5. Подстановка команд и арифметика

```bash
NOW=$(date)
echo "Сейчас: $NOW"
SUM=$(( 10 + 20 ))
echo "Сумма: $SUM"
```

## 7. Задание 6. Переменные окружения: просмотр и изменение

### 7.1. Просмотр переменных окружения

```bash
env | less
printenv | less
printenv PATH
printenv HOME
set | less        # все переменные оболочки, включая локальные
```

### 7.2. Изменение переменной окружения для всех пользователей

**Способ 1. `/etc/environment`** — простой файл `KEY=value`, без `export`:
```bash
sudo nano /etc/environment
```
Добавьте:
```
LAB_GLOBAL="global-value"
```
Сохраните. Изменения применятся после повторного входа.

**Способ 2. `/etc/profile.d/`** — скрипт с `export`:
```bash
sudo nano /etc/profile.d/lab_env.sh
```
Добавьте:
```bash
export LAB_GLOBAL="global-value"
export EDITOR="nano"
```
Сохраните. Проверьте после нового входа:
```bash
echo $LAB_GLOBAL
echo $EDITOR
```

### 7.3. Изменение переменной окружения для конкретного пользователя

Добавьте в `~/.bashrc` пользователя `debian`:
```bash
echo 'export LAB_USER="user-value"' >> ~/.bashrc
echo 'export TZ="Europe/Moscow"' >> ~/.bashrc
source ~/.bashrc
```
Проверьте:
```bash
echo $LAB_USER
echo $TZ
date
```

### 7.4. Использование переменных окружения в командах

```bash
echo "Глобальная: $LAB_GLOBAL"
echo "Пользовательская: $LAB_USER"
printenv LAB_GLOBAL
env | grep LAB_
```
Пример использования в команде:
```bash
EDITOR=nano crontab -e   # редактор для crontab
TZ=UTC date              # временная зона только для команды
```

## 8. Задание 7. Шаблоны подстановки (globbing)

Оболочка раскрывает шаблоны в имена файлов **до** выполнения команды.

### 8.1. Символы `*`, `?`, `[...]`

```bash
ls /etc/*.conf
ls /etc/?ost*
ls /etc/[abc]*
ls /etc/[[:digit:]]*
ls /etc/[!a-z]*
```

### 8.2. Фигурные скобки `{...}`

```bash
echo file{1,2,3}.txt
echo {a,b,c}{1,2}
cp /etc/hosts /etc/hosts{,.bak}
ls -l /etc/hosts*
```

### 8.3. Использование с `find`

```bash
find /etc -maxdepth 1 -name "*.conf"
find /var/log -name "*.log"
```

> **Важно.** Шаблоны раскрывает сама оболочка. Если заключить шаблон в кавычки, он не раскроется:
> ```bash
> echo "*.conf"
> echo *.conf
> ```

## 10. Задание 9. Потоки ввода-вывода: stdin, stdout, stderr

В Linux у каждого процесса есть три стандартных потока:
- `stdin` — дескриптор `0`, стандартный ввод;
- `stdout` — дескриптор `1`, стандартный вывод;
- `stderr` — дескриптор `2`, стандартный вывод ошибок.

### 10.1. Перенаправление stdout

```bash
echo "Hello" > /tmp/out.txt
cat /tmp/out.txt
echo "World" >> /tmp/out.txt
cat /tmp/out.txt
```

### 10.2. Перенаправление stderr

```bash
ls /nonexistent > /tmp/out.txt 2> /tmp/err.txt
cat /tmp/out.txt
cat /tmp/err.txt
```

### 10.3. Объединение stdout и stderr

```bash
ls /nonexistent > /tmp/all.txt 2>&1
cat /tmp/all.txt

ls /nonexistent &> /tmp/all2.txt
cat /tmp/all2.txt
```

### 10.4. Перенаправление stdin

```bash
wc -l < /etc/passwd
```

### 10.5. Here-doc и here-string

```bash
cat <<EOF > /tmp/here.txt
Строка 1
Строка 2
Пользователь: $USER
EOF
cat /tmp/here.txt

cat <<< "Текст из here-string"
```

### 10.6. Отправка в `/dev/null`

```bash
find / -name "*.conf" 2>/dev/null | head
```

## 11. Задание 10. Конвейер (`|`)

Конвейер передаёт `stdout` одной команды на `stdin` следующей.

### 11.1. Простые конвейеры

```bash
ls -l /etc | grep conf
cat /etc/passwd | cut -d: -f1 | sort | head
ps aux | grep bash | grep -v grep
history | tail -20 | less
```

### 11.2. Подсчёт и фильтрация

```bash
ls /etc | wc -l
cat /etc/passwd | awk -F: '{print $1}' | sort | uniq | wc -l
```

### 11.3. `tee` — вывод на экран и в файл

```bash
ls -l /etc | tee /tmp/etc_list.txt | grep conf
cat /tmp/etc_list.txt
```

### 11.4. Конвейер с перенаправлением stderr

```bash
find / -name "*.conf" 2>/dev/null | grep ssh | head
```
